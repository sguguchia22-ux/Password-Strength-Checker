პაროლების სიმძლავრის შემმოწმებელი და Brute-Force შეტევის სიმულაცია
🚧 სტატუსი / Status: პროექტი მზადების პროცესშია (Work in Progress — მასალები და სიმულაციის ფაილები მალე აიტვირთება)

📌 პროექტის შესახებ (About the Project)
ეს არის ინტერაქტიული საგანმანათლებლო რესურსი კიბერუსაფრთხოებისა და ციფრული წიგნიერების მიმართულებით. პროექტის მიზანია მოსწავლეებისა და ტრენინგის მონაწილეებისთვის თვალსაჩინოდ აჩვენოს:
🔹 რამდენად მნიშვნელოვანია ძლიერი და უნიკალური პაროლების გამოყენება;
🔹 რა პრინციპით მუშაობს ავტომატიზებული შეტევა (Brute-Force Attack);
🔹 რამდენი დრო სჭირდება კომპიუტერულ ალგორითმს სხვადასხვა სირთულის პაროლის გასატეხად.

This is an interactive educational resource in Cybersecurity and Digital Literacy, designed to visually demonstrate the importance of strong passwords and estimate how long it takes for a Brute-Force algorithm to crack passwords of varying complexity.

⚙️ დაგეგმილი კომპონენტები (Planned Components)
🛡️ პაროლის სიმძლავრის ანალიზატორი (Password Strength Checker): პაროლის სიგრძის, სიმბოლოების ტიპებისა და ენტროპიის შეფასება რეალურ დროში.
⏱️ Brute-Force სიმულაცია (Brute-Force Simulation): პაროლის გატეხვის სავარაუდო დროის დემონსტრირება.
📘 საგანმანათლებლო გზამკვლევი (Educational Guide): პრაქტიკული რეკომენდაციები და სავარჯიშოები უსაფრთხო პაროლების შესაქმნელად.
